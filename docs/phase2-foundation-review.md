# Technical review of the new Phase 2 foundation

Two separate AI reviewer contexts reviewed the new review/import/analysis and context APIs read-only before publication. This is technical AI review, not human linguistic approval. All concrete findings below were corrected with deterministic regression coverage; final integration results are in the Phase 2 report.

| Severity | Location / reproduction | Root and correction | Regression |
|---|---|---|---|
| High | `ContextCorrectionEngine.MapToCurrentSnapshot`: generate eligible→ineligible without a protected span, then map under an otherwise identical request protecting eligible. | Document/target identity did not bind policy. Results now bind complete language, target/context structure, metadata and protected-span request identity, and target candidates are revalidated at mapping. | `ResultsCannotReplayAcrossProtectionLanguageOrMetadataPolicies` |
| Medium | Same mapper: change result disposition to Rejected while retaining edits; or reuse bold result under italic request. | Disposition/metadata were not checked. Non-accepted nonempty edits and metadata mismatch now fail. | Same regression |
| Medium | `BuildPrompt`: same neighbor before vs after target. | Context ordering omitted relation to target; before/after labels are now explicit. | Context mapping/prompt tests |
| High | `LinguisticReview`: justified=false, meaningPreserved=null alongside a good proposal reported1/1. | Unknown-first boolean conjunction dropped definite failures. Any false now yields false; only unresolved conjunctions remain unknown. | `DefiniteFailuresRemainInDenominatorWithOtherUnknownJudgments` |
| Medium | Bound null sourceFamily→empty string reused approval while changing family counts. | Optional-value coalescing erased absence. Tagged optional values distinguish absent/empty; blank optional IDs rejected. | `StaleSourceCandidateAnnotationAndDecisionVersionFail` |
| Medium | Approved passage with allDefectsRepaired=null showed full adjudication coverage but no metric-specific judgment coverage. | Finalized workflow state differs from known metric judgment. Each metric now reports known-judgment coverage. | `UnknownPassageJudgmentsStayOutOfSuccessDenominator` |
| High | Analysis created delivered passage subjects for rejected en-20 no-ops. | Would allow rejected source preservation to receive successful-delivery quality credit. | High | Analysis copied legacy source report model hashes without unverified binding caveat. | Dataset verification did not prove trace/model association. | Medium | Incomplete `Please receive it` has extracted text but empty diagnostic raw edits. | Parsed scoring incorrectly reused empty raw edits. | Medium | `annotationVariants[0]` would discard conflicts. | First-variant selection violates dataset protocol. Multiple variants now fail pending explicit adjudication; current263 each have one. | Conflicting-variant import guard; existing annotation audit regressions |
