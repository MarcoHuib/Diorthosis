# Phase 3 predeclared protocol v1

Frozen before new inference, 2026-10-20. Base `09e89d164b2a6a3711044fc007ad4749ddec36e4`; one dependent experimental branch. Scope: linguistic correction only. Production prompt v3 and default greedy pipeline remain unchanged.

Compare the 20 fixed passages in `benchmarks/phase3/v1/panel.jsonl` (10 per language, six annotated error passages and four proposed clean passages each). These are rights-cleared AI-authored Phase 2 development inputs, exposed during development; no held-out claim. Retain full original metadata and run exact/near duplicate audit. Do not revise cases or references after outcomes.

1. Acquire only small reviewed development assets: WeCantSpell.Hunspell 7.0.1 under its MPL-1.1 path, unmodified in a separate experimental assembly; OpenTaal commit `ad0351b7c1a862f05d88131046a054f1cc84944a` under BSD-3-Clause; ESDB/SCOWL-derived 2026.02.25 US and GB dictionaries after copyright verification. Preserve notices, immutable revisions, bytes and SHA-256. No new weights, native dependency or application download path. Record package source availability and MPL obligations; no production adoption.
2. Existing Ministral 3B Q4_K_M only: greedy production baseline; dictionary-only diagnostics; separately versioned untrusted pre-inference hints, greedy; post-inference diagnostics on baseline (flag recognized-source/unrecognized-target, never block unknown vocabulary automatically); one stochastic control and three-sample voting (seeds 101, 202, 303, temperature 1, top-p 1, top-k disabled, min-p disabled, repeat penalty 1). Cap 256 output tokens, 90 seconds per generation, context 4096, nine CPU threads. The control is sample 101 of the voting pool, disclosed as reused. No independent sample-count claim.
3. Use the existing deterministic grapheme diff. Add auditable localized operations plus conservative passage-wide dependency grouping until a reliable grammatical dependency analyzer exists. Strict majority counts generation IDs once; reject conflicting spans and dependency-incomplete combinations. Final candidate must pass the complete existing validator. This is an adaptation, neither GECToR nor a reproduction of ERRANT-based voting. Identical generations expose zero observed diversity; no confidence bonus.
4. Five samples only if three-sample results show at least one reference-repair gain or removal of an AI-assessed unnecessary change without new critical failure. Combined pre-hint voting and larger-model reruns require isolated benefit first. Post-diagnostic analysis may be replayed without inference. Otherwise defer explicitly.

Acceptance: tested offline dictionary adapter and diagnostics; negative voting/safety tests; actual bounded inference where available; evaluator v3.1 reused; immutable raw outputs, literal prompts, seeds, completion states, proposed/delivered edits, model/runtime/native/dataset hashes and measured resources. Publish blinded before/after cards with separate lineage and a ChatGPT review prompt. Preserve AI decisions and uncertainties as `reviewerKind: ai`; only genuine external human adjudication can enter human metrics. AI-assisted linguistic reading is the primary development feedback; exact reference matches are secondary diagnostics. Report gains, losses and false flags by language, and uncertainty rather than production approval.

Risks: dictionary coverage and dialect bias, correlated samples, conservative dependency grouping losing repairs, validator false rejection and unresolved semantics, platform/Native AOT compatibility and resource overhead. Alternative is the unchanged baseline. Native Hunspell/Nuspell and a trained GECToR model are unnecessary for this isolated experiment. Stop a blocked arm, record evidence and continue independent arms.
