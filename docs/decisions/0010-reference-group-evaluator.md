# ADR 0010: Separate reference recall, grouping and adjudication

Date: 2026-10-20. Status: experimental evaluator `reference-groups-3.0.0`; v1/v2 unchanged.

Reconstruct the delivered candidate, then derive a deterministic grapheme diff instead of scoring submitted edit boundaries. Match source annotations and explicit dependency groups atomically against their accepted replacements. Local matched repairs retain recall even with unrelated lexical edits; strict whole-passage reference matching remains separate. Report categories from repaired annotation indexes. Proposal groups are annotation/dependency units plus unresolved canonical residual edits. Mixed-category dependencies appear in all-category precision only, to avoid counting a proposal in several category denominators. Category recall still includes each annotation once.

Reference-group precision is a diagnostic proxy, not linguistic precision. Residual grouping still uses a canonical diff and requires adjudication; a deterministic general-purpose bilingual linguistic grouper is not established here. Independently supplied proposal labels bind to exact candidate SHA-256 and proposal ID, with reviewed-group coverage. Do not describe unreviewed reference matching as true linguistic precision or uncredited changes as necessarily wrong. No human labels were supplied in this checkpoint.

NFC equivalence applies only to comparison copies; original offsets and output remain literal. Smart/straight apostrophes require explicit accepted alternatives. Clean preservation is literal. Missing predictions produce null passage acceptability and missing coverage, not successful clean no-ops. Recall counts missed predictions as missed errors, while clean/passage proportions use observed predictions with coverage separately reported. Every ratio carries counts and null empty denominators. Wilson 95% intervals are descriptive; independence is not claimed for development/template data. No superiority conclusion or paired bootstrap is warranted here.

Alternatives rejected: replacing v1/v2 in place, granting unknown alternatives credit, globally converting punctuation, counting arbitrary submitted hunks as proposals, or treating all sentence changes as one linguistic unit. Reference combinations are bounded (256 per group/case, 32 alternatives per annotation); an exhausted complete-reference expansion yields unknown acceptability. Partial ambiguous alignment stays unresolved. Dependency metadata is optional for legacy data; absence does not prove linguistic independence and reviewers must add it.

Validation: representation variants, cross-annotation edits, mixed categories, lexical-veto separation, speech-act extras, apostrophe/restructuring sensitivity fixtures, NFC, dependent edits, missing/rejected outputs, null ratios, candidate-bound reviews. All 99 deterministic tests passed; one weight-dependent test skipped. The four saved Ministral/EuroLLM9B v1 metric arrays reproduce exactly; new v3 replay reports are separate. No historical score, annotation or trace was replaced. No model inference or latency/memory benefit was measured.
