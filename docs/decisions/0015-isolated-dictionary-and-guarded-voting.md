# ADR 0015: Isolate dictionary hints and dependency-guarded voting

Experimental, 2026-10-20. All default correction behavior and the production prompt stay unchanged. A nullable sampling policy explicitly enables seeded stochastic research; a null policy preserves the existing greedy sampler and termination tracking. No new model weights or foreign-origin taggers are introduced.

The separate Experiments assembly references unmodified WeCantSpell.Hunspell 7.0.1 (NuGet source commit `ab5709d95b2d23541984d22baa0ab2d1e783582f`). Select the MPL-1.1 option. This is commercially usable copyleft, **not permissive**; only a managed development dependency, never a native release dependency. Keep the package's exact notice and make covered source available at the pinned upstream revision if distributing the experimental binary. Any covered-source modifications require MPL notices/source availability. No upstream modifications are made. Production redistribution/Native AOT release packaging remains a separate review; do not infer permission to bundle in the product. net10.0 has no transitive package dependencies. Native Hunspell and Nuspell add unnecessary interop/native redistribution work for this experiment.

OpenTaal's matching `.dic`, `.aff`, `datetimeversion.txt`, and license are pinned together at `ad0351b7c1a862f05d88131046a054f1cc84944a`; select BSD-3-Clause and preserve its full attribution. The date/version file says 2.20.23; the affix header can carry an older internal version. Both literal hashes remain authoritative. English dictionaries are official SCOWL-derived US and GB-ise 2026.02.25 size-60 releases, source `7e99edab8e32f9f9ea2b15f249ca8d4d67237410`. Preserve both complete README notices including the affix-file BSD terms and SCOWL copyright. The copyright discloses COCA-derived information and the upstream author's rights assertion; this is provenance disclosure, not an independent training-data/IP audit. No Australian, large or WordNet database assets are redistributed. US/GB union is the default experimental checking policy; explicit dialect policies are supported without rewriting source dialect.

Dictionary absence is diagnostic, never proof of an error. Hints are untrusted JSON, may mislead inference, and have a separate version. Post-diagnostics reconstruct complete changed words even when the diff is a one-character insertion (`start` to `startt`). They expose recognized-to-unrecognized transitions without rejecting legitimate names, new vocabulary or terminology. They do not solve valid-word agreement or split compounds.

[GECToR](https://aclanthology.org/2020.bea-1.16/) trains a sequence tagger with token transformations. We only reuse localized operation ideas over the existing deterministic UTF-16/grapheme diff. KEEP content remains literally copied; operations retain exact source spans and passage dependency linkage. No GECToR weights, architecture or performance is reproduced. Equivalent reconstructed passages canonicalize before voting; no numerical source positions are requested from the LLM.

[Goto et al.](https://aclanthology.org/2026.bea-1.60/) count extracted edits across single-model samples, then retain a threshold. Their settings use eight candidates, development-tuned thresholds, temperature/top-p 1, four-shot prompts and ERRANT/JP-ERRANT. Their [MIT-licensed implementation](https://github.com/gotutiyan/gec-llm/blob/a2dfc08bb01b4516eb402398c2fe14129ed8f45e/src/gec_llm/ensembles/voting.py) counts edit keys and greedily removes overlap in descending vote order. It was read as research evidence, not copied or added as a dependency.

Our bounded adaptation uses three candidates (five conditional), fixed strict majority, existing zero-shot prompt and deterministic source diff. IDs count once per edit, rejected/incomplete outputs do not shrink the denominator, and identical outputs expose no observed diversity. Source overlap causes rejection rather than selecting an arbitrary conflicting edit. **Dependency guard:** without a reliable dependency parser, a nonempty voted combination must equal at least one complete validated candidate. Otherwise return NeedsReview with no deliverable edits. This is intentionally more conservative than the paper and can suppress correct partial salvage. It also means the experiment cannot establish the benefits of unrestricted edit recombination. Final passage validation always runs; even validated consensus is not proof of semantic correctness.

Rejected alternatives: rebranding failed direct-offset prompts as GECToR; naïvely applying independent hunks; treating deterministic repeats as independent confidence; auto-blocking dictionary-unknown words; tuning thresholds on the small observed outcomes. Exact reference diagnostics, AI linguistic feedback and independent human validation remain distinct evidence layers.

2026-10-21 follow-up from the frozen outputs: local grouping now explicitly marks repeated whole-word alignments that reconstruct the same passage at different spans. Voting 1.1 also excludes newly introduced letters outside the inspected Latin ranges when they were absent from the source. This narrowly addresses the observed Armenian-script corruption in a Dutch sample; it preserves existing foreign-script content and Latin diacritics. It is an experimental safety filter, not a semantic-equivalence proof or a change to production defaults. The original 1.0 run stays frozen; deterministic replay verifies unchanged delivered voting analyses on this panel, without relabeling the original run as new inference.
