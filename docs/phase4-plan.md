# Phase 4 preregistered protocol

2026-10-21. Base: verified PR #5 head `6f78219ef57332b88c047cac51338b8604adadb3`, seven passing CI jobs. Branch `feat/phase4-prompt-quality` targets `feat/linguistic-quality-experiments`. No production prompt promotion, merge, release or model acquisition.

Scope: opt-in prompt selection, frozen original fictional NL/EN development panel, paired greedy local 3B inference, diagnostics, blind review export and measured report. Reuse Phase 3 extraction/validation and evaluator v3; no new acceptance heuristic. Alternative of adding spelling/voting/normalization guards is deferred because it would confound linguistic generation quality.

Panel: 100 passages per language, each 10 prompt-development (6 erroneous, 4 clean), 70 selection (42 erroneous, 28 clean), 20 confirmation (12 erroneous, 8 clean). All labels are AI-generated, preparer inspected, independently unvalidated. Prompt examples use development items 1, 2, 7, 8 only. Creator knows historical failure categories. No old passages reused. Confirmation is inference-unseen, author-exposed; it is not an independently sealed population test. Do not modify annotations or examples after inference. Dataset hashes in `benchmarks/phase4/v1/freeze.json` are fixed before model runs.

1. Representation: on the same 140 selection inputs, run exact v3 escaped JSON, literal-Unicode JSON, plain UTF-8 block with collision-resistant delimiter and explicit untrusted-data framing. B changes the JSON encoder only. C necessarily changes the framing and adds an instruction boundary; do not attribute a C effect purely to Unicode. No Unicode normalization. All use current validator, official 3B Q4_K_M SHA-256 `9ed150d4367e68df0ac8e1540f6ddc65b42d0ee26378329d1ecbca60f93fc5f8`, context 4096, 9 CPU threads, 256 output tokens, 90s timeout, greedy/EOG. Counterbalance arm order by case index; no stochastic samples or votes.
2. Select representation for further research using provisional reference diagnostics, literal clean preservation, abstention and observed safety. No independent linguistic winner inferred. If evidence is inconclusive, prefer B as a compact controlled research substrate while retaining A as production; explain the choice before the next run. Do not tune source-specific instructions.
3. On those same selection inputs, compare original instructions against isolated added minimal-edit policy, isolated added language checklist, and four development-only few-shot examples. Original arm can be reused from stage 1 with exact lineage, not counted as fresh inference. All prompt variants frozen before stage 1. Combined minimal+few-shot is permitted only if isolated arms both show improved repair without worse clean preservation, no observed critical regression, and qualitative assessment supports complementary gains. Otherwise skip and explain.
4. Lock one exploratory candidate before touching confirmation outputs. Run it and exact v3 once on 40 confirmation inputs if a candidate warrants it. If no defensible candidate exists, leave the panel unopened to inference. Never tune prompts to confirmation failures or repeatedly inspect it. Report selection and confirmation separately.

Analysis: evaluator v3 reference groups are diagnostic proxies, not linguistic truth. Save all attempted cases, failures, raw/extracted/delivered layers, rejection/abstention, model/runtime/software hashes, latency, literal-prompt content token count (template/BOS excluded), sampled process RSS every 50 ms. Paired gains/losses by source case and annotated error; preserve unknown/unlisted alternatives. Report clean source fallback separately from eligible unchanged output. Rejection is abstention, never successful repair. Independent meaning, unnecessary edits, new errors, valid alternatives, local repair and whole-passage quality require review. No population percentages or 90% quality claim.

Acceptance: all 200 passages frozen and audited, complete paired coverage for every run including failures; exact A/v3 parity, B JSON roundtrip and C framing tests; historical evidence unchanged; real local weight inference under enforced network denial; reproducible comparisons; blinded ZIP with exact source/candidate bindings and import instructions, separate lineage; all .NET/tooling tests; Native AOT probes and six-RID CI. If independent review is unavailable, deliver a complete packet and explicitly provisional rankings. Promotion requires separately approved evidence satisfying all user gates, including no critical semantic regression, acceptable clean/latency/memory, regression tests and passing current-head CI.

Risks: AI labels and synthetic distributions, creator exposure, finite small samples per category, uncertain regional judgments, deterministic but hardware-specific inference, model responses ignoring boundaries, process RSS/cache confounding. Frozen original annotations remain unchanged even when a valid alternative is found; separate AI review can dispute them. Stop at a reproducible externally reviewable checkpoint; zero fabricated human approvals.
