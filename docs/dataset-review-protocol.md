# Dataset audit and independent review

Run `dotnet run --project src/Diorthosis.Benchmarks -- audit-dataset <cases.jsonl> <NEW-directory> [threshold]`. Output directories must not exist. Contract `dataset-audit-1.0.0` uses SHA-256 of literal UTF-8 input, ordinal ordering, literal annotation signatures with sorted/deduplicated alternatives, and UTF-16/grapheme source validation. Original records are never modified. Every ID maps to a language/input group; disagreement variants retain all original annotations and member IDs. The grouped candidate is deliberately a review format, not a benchmark case file. Choosing the first annotation would silently adjudicate disagreement and is forbidden.

Near matching first diagnoses NFC/whitespace equality and case-insensitive equality, then Dice similarity of sets of adjacent word/punctuation tokens. Default threshold 0.85 is configurable, invariant to input ordering, and deliberately heuristic. Negation, punctuation and word order can make a near pair materially different. No near pair is merged. Set similarity misses repetition/multiplicity and distant template relations; a pairwise 5000-input limit prevents unbounded quadratic work. Review larger collections in declared source families before raising limits.

`check-splits <manifest.json> [threshold]` reads an array of `{ "partition": "development", "path": "relative/cases.jsonl", "sourceFamilies": { "case-id": "template-family" } }`. It returns exit 1 for cross-partition exact, near, or declared-family overlap. It compares across languages too. Missing family metadata is reported, never inferred as independence. Assign whole source/template families to development, prompt-selection or held-out partitions before any model inspection. These 600 records and the exposed 44 smoke cases belong to development; none is relabeled held-out. Do not attempt a random sentence split of this collection.

Review process:

1. Rights/source review: confirm reusable synthetic/cleared material, register provenance, template family, language/variant, document context and SHA-256. Unknown provenance blocks final approval.
2. Two qualified independent reviewers per language, without model predictions, inspect every source and annotation. Record reviewer identity/qualification, timestamp and policy version outside anonymous score summaries. No reviewer is assigned by this tool.
3. Mark all genuine errors, exact UTF-16 spans, alternatives and acceptable full passages, register/regional policy, severity, dependency groups, protected facts/spans, context needs and clean status. Apostrophe alternatives are literal policy choices; NFC equivalence is a separate scoring rule. Zero-length insertions must use grapheme boundaries. Resolve overlaps explicitly.
4. Adjudicate disagreement with reasons and provenance. Retain original judgments. AI-generated judgments remain proposals; they cannot supply independent sign-off.
5. Freeze approved data and partition manifests by checksum before prompt/model selection. Run split checks; resolve flagged pairs by family grouping or documented human assessment, never by deleting the evidence. Final test cases must stay unseen during development.
6. Report inter-reviewer agreement, unresolved cases, independent family counts, clean/error/category counts and sampling limitations. Target 200 varied errors and about 300 clean passages per language for later quality work; do not manufacture repetitions to meet counts. Wilson intervals assume independent Bernoulli observations; repeated template groups violate that assumption.

Coverage gaps requiring new reviewed material: NL spelling/conjugation/participles/dt, compounds, subordinate ordering, punctuation; EN spelling/agreement/tense/aspect/contractions/UK-US variants; fragments, technical/domain vocabulary, mixed languages, negation/modality/conditional and temporal meaning, long multi-error passages, and document formatting/source mapping. Existing category tags do not establish coverage of these subtypes. Only 15 unique clean inputs per language exist in the original collection. No new synthetic generator is added: quality/provenance review of existing material is higher value than increasing unreviewed volume.
