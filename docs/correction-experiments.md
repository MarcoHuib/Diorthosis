# Controlled development experiments

Status: experimental infrastructure. No prompt or format replaces `diorthosis-correction-v3`.

Baseline uses the exact frozen prompt. LanguageMinimal adds Dutch/English minimal-correction rules with full-passage output. FewShot adds two synthetic examples per language. StructuredOffsets and StructuredFragments retain the minimal policy but change output representation. Offset JSON uses the existing array contract with exactly four properties: `start`, `length`, `originalText`, `replacementText`, using literal UTF-16/grapheme spans. Fragment JSON uses exactly `originalText`, `replacementText`, `prefix`, `suffix`; literal immediately adjacent context must uniquely locate the fragment. Ambiguity requires review. Never select an arbitrary occurrence. All edits are validated together through the same passage/protected-span policy; no partial salvage.

GBNF is opt-in for StructuredOffsets only. The pinned LLamaSharp 0.27.0 cached API exposes `GreedySamplingPipeline.Grammar` and `Grammar(gbnf, root)`; this experiment uses a narrow fixed-key grammar rather than claiming general JSON Schema support. Grammar only constrains syntax. Invalid offsets/protected edits/incomplete generations remain blocked. No runtime upgrade or new dependency.

Predeclared panel: `benchmarks/rehabilitation/v1/experiments/development-panel-8.jsonl`, four Dutch/four English exposed smoke inputs (two erroneous, two clean per language). It covers a participle, subordinate clause, dependent agreement, word order and technical clean preservation. This tiny purposive panel tests contract feasibility, not generalization, recall gates, statistical superiority or model selection. No tuning after inspection. Few-shot examples are development material and must be excluded by family from future held-out tests.

Compare six configurations sequentially: Baseline, LanguageMinimal, FewShot, StructuredOffsets, StructuredFragments, and StructuredOffsets with grammar. All use the existing verified Ministral 3B Q4_K_M, exact same panel, 4096 context, nine CPU threads, greedy decoding, 256-token cap, EOG policy, 90-second per-case timeout, pinned CPU-only backend and host. Match baseline rerun to the current safety policy; old 128-token reports are historical context only. Model hash is checked against the explicit provenance file before inference. Every run requires a new directory, writes a running/failed/complete manifest, predictions, synthetic trace, reference metrics and sampled resource measurements separately. Source text logging is confined to explicitly selected rights-cleared benchmark fixtures; normal correction logs no candidate text.

Command: `dotnet run --project src/Diorthosis.Benchmarks -c Release --no-build -- experiment <panel.jsonl> <local.gguf> <NEW-directory> <Variant> 256 <provenance.json> [--grammar]`. Set `DIORTHOSIS_EXPERIMENT_COMMIT`, `DIORTHOSIS_EXPERIMENT_CPU`, `DIORTHOSIS_EXPERIMENT_RAM_BYTES` to inspected values, otherwise manifest values remain unknown. The model/review-reference manifest is a reproducibility assertion, not an automatic license approval. Exact native library hashes are captured. Initialize the macOS ARM64 CPU backend from ADR 0006 before running; do not use the stock Metal-linked package for these comparisons.

Acceptance: deterministic contract tests pass; no malformed/unaligned edit can be applied; native grammar/EOG execution is demonstrated where possible; no production promotion without new independent annotations and broader quality/resource evidence. Actual executed results and platform limitations are recorded separately in the final quality-engineering report. Foreign-platform grammar inference, long-output memory behavior and complete JSON Schema compatibility remain unverified.

The first grammar run (`offset-gbnf` SHA-256 in its manifest) allowed trailing `ws` at the root. Two outputs continued sampling whitespace after a complete array until the token cap; neither was accepted. Version `offset-gbnf-1.1.0` removes only root trailing whitespace so the completed array can terminate at EOG. The original grammar remains available as `OffsetGrammarV1`, and the initial run is frozen. A separate rerun tests this concrete termination defect; it does not tune linguistic rules or references. Prompt building and fragment alignment avoid reflection-based JSON serialization so Core's experimental path can be exercised under Native AOT.
