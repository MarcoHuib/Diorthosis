# Retained external GPT-6 assessments

All 18 user-submitted result ZIPs and their exact extracted members are in `batches/batch-NN/original`. Each `validation.json` describes original packet identity, strict main decisions, supplementary scope, actual coverage and import status. Each `imported` directory is produced by the existing strict importer and C# adjudicator. Batch 07 alone has a separate byte-preserving candidate-only supplementary subset; its six source-only extras remain in the originals and validation report.

`coverage.json` and `VALIDATION.md` reconcile all 1075 unique bound subjects. `combined` retains exact concatenated decision lines, separately indexed original provenance, the parent C# report, and an explicitly empty human adjudication file. There is deliberately no invented aggregate reviewer provenance. Coverage of complete main records does not mean every nullable linguistic criterion is known.

`analysis` projects these retained judgments onto 920 exact saved generation occurrences, with 564 annotated-error generation occurrences. Layer and candidate duplicates never increase independent evidence. It includes per-condition/language metrics, paired gains/losses/unknowns, raw/parsed/delivered/rejected assessments, retained preparer disagreements and sensitivity, ranked defects, canonical Unicode diagnostics and reference discrepancies. No new linguistic judgment, inference, frozen-reference edit or production change is generated by these scripts.

Authority: AI diagnostic evidence only; reviewer identities/builds/context are declarations. `independenceDeclared=false`; **zero human approvals**. Human-finalized C# metrics remain zero. See [full report](../../../../docs/phase4-external-review-report.md) for criteria, limitations and the decision to retain production v3.

After a Release build, reproduce without model weights or inference:

```sh
python3 scripts/verify-phase4-external-reviews.py --reproduce /tmp/NEW-phase4-external-reproduction
```

The top-level artifact manifest hashes all retained files and analysis/import implementations; it excludes only itself. Original frozen experiment evidence remains under `benchmarks/phase4/v1` unchanged. Validation timing/CI provenance is separate from original model/runtime identities.
