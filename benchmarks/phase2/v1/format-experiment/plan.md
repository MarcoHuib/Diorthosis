# Predeclared bounded format experiment

Purpose: determine whether the saved 3B model-generated-offset failures recur in available larger verified local14B and EuroLLM9B models. Prior negative evidence already covers 3B's small panel. This follow-up repeats3B as a concurrent contract baseline and tests the larger models; no broad prompt search, no downloads, no new interface or default promotion.

Hypothesis: grammar-constrained structured offsets may reach natural EOG while still producing invalid source alignment; a larger model alone may not fix that interface. Contrast: full-passage production v3 prompt with deterministic diff **versus the already implemented structured-offset protocol plus its existing grammar**. The principal independent variable is the output protocol; prompt instructions and grammar are part of that protocol. Model identity is held fixed within each contrast. Do not attribute results separately to grammar or prompt wording.

Models: exact existing local3B,14B and EuroLLM9B Q4_K_M assets, hashes/revisions in adjacent provenance files; EuroLLM is the saved pre-2512 artifact, not the newer untested checkpoint. These were previously reviewed as European-origin Apache-2.0 evaluation candidates in repository documents. No release rights, training-data completeness or distribution approval is newly asserted.

Fixed panel: `benchmarks/rehabilitation/v1/experiments/development-panel-8.jsonl`,4NL/4EN, explicitly exposed/unreviewed. All arms use identical cases and current validator/evaluator3.1. Max48 generations total (3models ×2arms ×8cases), run sequentially. CPU-only9threads,4096context,greedy,256max output tokens,90second per-case timeout, no random sampler. Machine: AppleM4,32GiB,macOSARM64; native backend pinned in manifests. OS file cache is uncontrolled. Hash assets before loading; no fallback download.

Success criterion: protocol must improve delivered reference repairs on the same cases without new source-alignment failures, protected-content violations or increased unjustified changes, while reaching EOG. Independent linguistic benefit cannot be determined until real adjudications are supplied. Rejection criterion: malformed source alignment, unsafe candidate, truncation, or lower delivered coverage means no diagnostic basis for promotion. Any timeout/partial run is retained and labeled failed. Frozen production prompt remains unchanged regardless of this tiny exposed panel's outcome.

Record exact model/native/prompt/dataset hashes, source commit, termination, validity, per-case output/disposition/reason/latency and sampled process working set across model load and inference. Sample every100ms; peaks may be missed and system memory pressure is not measured. Keep new timing measurements separate from historical timing. OS network denial and diagnostics disabled enforce no network inference. Existing negative3B artifacts remain immutable.
